This is a sub-command of the Committee Review System. Read and follow `skills/committee/SKILL.md` with intent: **add**.

The user has invoked `/committee:add`. If they included a quoted description (e.g., `/committee:add "Head of QA at Netflix"`), generate the persona in one step following `generation-guide.md`. Otherwise, ask them to describe the new member. Save to `favorites/`, update `favorites/_index.md`.
